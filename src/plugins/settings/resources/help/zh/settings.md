## 设置

设置是应用选项所在的对话框：既有 **常规** 和 **外观** 这样的内置页面，也有由标签页贡献的分区。标签页分区始终可见，与当前会话无关。

### 打开设置 {#open-settings}

- **文件** → **设置**（`Ctrl+,`）。
- **查找操作** — `Ctrl+Shift+P`，然后输入页面名（常规、外观、键盘……）。
- **了解更多** — 在设置有对应帮助主题时打开该主题。

### 在设置中搜索 {#search}

搜索框位于侧边栏上方。每个匹配的分区显示为单独一行，无论匹配藏得多深（控件名、分组标题、任何语言）。激活某一行会打开该分区并高亮匹配项。`Esc` 清空搜索并恢复完整侧边栏。

### 常规 {#general}

- **语言** — 界面语言：en / ru / zh / pt_BR。
- **主题** — auto / light / dark。
- **系统通知** — 打开或关闭操作系统通知。
- **启用调试日志** — 写入详细日志以便排查问题。

### 外观 {#interface}

- **UI模式** — **初学者**、**高级** 或 **专家**；默认是 **初学者**，首次运行的选择也落在这里。
- **UI字体** — 内置、系统默认或自定义字体族。
- **界面缩放** — 缩放整个界面（0.5–2.5）。
- **最大名称长度 (UI)** — 限制显示名称的长度。

### 性能 {#performance}

- **后端** — 渲染后端；可选项取决于平台，切换后可能需要重启。

### 图像比较 {#image_compare}

图像比较选项，始终可用：

- **缩放插值** — 缩放的采样质量。
- **放大镜移动** — 拖动时让镜头跟随指针更平滑；下面的 **激光平滑** 行平滑放大镜辅助线。两行各有自己的方法。
- **放大镜重叠红色高亮** — 拖动放大镜时，其捕获环被其他放大镜遮住的部分会高亮；**自动为新放大镜着色** 给每个新镜头不同的颜色。
- **录制帧率** — [视频编辑器](help://workspace.image_compare.video)的采集速率。
- **加载时自动裁剪黑边** — 加载图像时裁掉黑边。
- **自动计算PSNR** / **自动计算SSIM** — 自动显示指标；默认关闭。

### 图库 — AI {#image-gallery-ai}

[图库](help://workspace.image_gallery.triage)中的 AI 功能使用以下设置。一次请求需要开关打开、一个 API 密钥和一个模型；只有密钥不够。密钥以未加密方式存储在本设备上。

- **启用 AI 图像分析** — 打开或关闭 AI 功能。
- **API 基础地址** — AI 服务的地址。
- **API 密钥** — 该服务的凭据。
- **模型名称** — AI 用于请求的模型。
- **回答 token 预算** 与 **推理强度** — 回答的限度：token 上限（留空 = 自动）以及模型作答前的推理量。
- **图片缩小（最长边）** — 发送给模型的最长边；**原图** 保留文件自身的字节。

### 键盘 {#keyboard}

快捷键按所有者分组——**平台**，然后每个标签页一组，例如 **Image Compare**。**重置** 恢复一个或全部快捷键。画布上的固定按键 `WASD` 和 `Space` 无法重新映射——见[快捷键](help://platform.hotkeys)。
