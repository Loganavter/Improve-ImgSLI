## 设置

应用行为集中在一个对话框中：既有内置页面，也有由工作区标签页添加的分组，例如 **图像比较**。标签页分组始终可见，不受当前会话影响。

### 打开设置 {#open-settings}

- **菜单** — 通过菜单打开 **设置**（`Ctrl+,`）。
- **工具栏** — 点击齿轮按钮。
- **查找操作** — 按 `Ctrl+Shift+P`，再输入页面名（**常规**、**外观**、**键盘**……）。
- **了解更多** — 为带帮助的设置项打开对应的帮助主题。

### 在设置中搜索 {#search}

搜索框位于侧边栏上方。每条匹配的选项各占一行，无论匹配位置在分组中多深（控件名、分组标题或任何语言）。点击某一行会打开该分组，并高亮命中的选项。`Esc` 清空搜索并恢复完整列表。

### 常规 {#general}

- **语言** — 选择界面语言：en、ru、zh 或 pt_BR。
- **主题** — 选择主题：auto、light 或 dark。
- **系统通知** — 开关操作系统的通知。
- **启用调试日志** — 写入详细日志，用于排查问题。

### 外观 {#interface}

- **UI模式** — **初学者**、**高级** 或 **专家** 单选；默认为 **初学者**，首次启动的选择也落在这里。
- **UI字体** — 选择内置、系统默认或自定义字体。
- **界面缩放** — 拖动滑杆调整整个界面的缩放比例（0.5–2.5）。
- **上限** — 限制相关数值，例如显示名称的最大长度。

### 性能 {#performance}

- **后端** — 选择渲染后端；可选值取决于平台，切换后可能需要重启。

### 图像比较 {#image_compare}

图像比较选项始终可用：

- **插值** — 设置缩放、放大镜和激光的重采样质量。
- **放大镜移动** — 让放大镜移动更平滑；插值方法在同一行选择。
- **放大镜重叠红色高亮** — 拖动放大镜时，其捕获环被其他放大镜遮住的部分会高亮显示。
- **自动为新放大镜着色** — 给每个新建的放大镜分配不同的颜色。
- **录制帧率** — [视频编辑器](help://workspace.image_compare.video)的采集帧率。
- **加载时自动裁剪黑边** — 打开图像时裁掉四周的黑色边框。
- **自动计算PSNR** / **自动计算SSIM** — 自动显示指标，默认关闭。

### 键盘 {#keyboard}

- **重映射** — 快捷键按所有者分组：platform / 图像比较 / 多图比较。
- **重置** — 重置单个或全部快捷键。
- **固定** — 画布上的 `WASD` 与 `Space` 无法重新映射 — 见[快捷键](help://platform.hotkeys)。
