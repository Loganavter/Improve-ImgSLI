## Навигация по холсту

Движение внутри холста сравнения: зум к курсору, панорама средней кнопкой и удержание `Space` для временного показа одной стороны.

### Зум и панорама {#zoom}

- **Зум** — `Ctrl` + колесо над холстом.
- **Панорама** — средняя кнопка мыши + перетаскивание.
- **Инструмент навигации** — отдельного нет; жесты работают прямо на живом холсте.

### Быстрый превью стороны {#quick-side-preview}

Жест холста сравнения (см. [Сравнение](help://comparison)):

- **Левая сторона** — `Space` + ЛКМ.
- **Правая сторона** — `Space` + ПКМ.
- **Отпустить** — назад к обычному разделу.
- **С объединённой лупой** — `Space+Shift` фиксирует сторону внутри линзы (см. [Лупа](help://magnifier)).

### Пока зум не 100% {#zoom-side-effects}

- **Подписи имён** — видны только при `100%` и возвращаются при вписывании.
- **Линия раздела** — долевая позиция (0–1); доля держится при смене зума.
- **Качество рендера** — интерполяция во всплывающей панели холста; смена бэкенда — в [Настройки → Производительность](help://settings#performance).
