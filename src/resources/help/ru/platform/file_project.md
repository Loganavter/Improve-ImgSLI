## Файлы и проекты

Здесь собрано, как загружать изображения в сессии, вставлять их из буфера обмена и открывать или сохранять портативные проекты — файлы, которые хранят раскладку сессий, настройки сравнения и копии исходных изображений.

### Загрузка изображений {#loading-images}

- **Добавить изображения** — кнопки добавления у сторон или действие через **Найти действие** (`Ctrl+Shift+P`) открывают выбор одного или нескольких файлов. В **Сравнении изображений** это **Добавить изображения (сторона 1)** и **Добавить изображения (сторона 2)**, в **Мультисравнении** — **Добавить изображения**.
- **Перетаскивание** — перетащите файлы в окно, и они попадут в список на стороне под курсором.
- **Вставка из буфера** (`Ctrl+V`) — изображение из буфера обмена вставляется в активную сессию; появляется подсказка направления, где клик по стрелке выбирает сторону списка, а `Esc` отменяет вставку.

:::figure{side=block width=280}
![Оверлей направления вставки](../../assets/platform/paste_overlay.jpg)
После `Ctrl+V` появляется подсказка: стрелка направляет изображение в левый или правый список, `Esc` отменяет вставку.
:::

### Списки {#lists}

- **Сравнение изображений** — левый и правый списки изображений независимы. Менеджер списка задаёт порядок, рейтинг и переименование, показывает путь и свойства, позволяет удалять изображения; подробнее: [Сравнение](help://workspace.image_compare.comparison).
- **Мультисравнение** — вместо двух списков изображения раскладываются по слотам: перетащите файл в нужный слот. Подробнее: [Обзор мультисравнения](help://workspace.multi_compare.overview).

Каждая сессия получает отдельную вкладку — см. [Вкладки](help://platform.tabs).

### Проекты {#projects}

Проект — это портативный файл `.imgsli`, который переносит состояние рабочей области между запусками и компьютерами.

- **Открыть проект** — `Ctrl+Shift+O` или **Найти действие**; пункт находится в меню **Файл**. Открытый проект называет активную вкладку именем файла и восстанавливает сессии, настройки сравнения (**Разделитель**, режимы различий, **Лупа** и связанные возможности) и встроенные копии изображений.
- **Сохранить проект** — `Shift+S` пишет изменения в текущий файл; если проект ещё не сохраняли, вместо этого открывается **Сохранить проект как…**. Сохранение также обновляет имя файла, если вкладку переименовали.
- **Сохранить проект как…** — `Ctrl+Shift+S` предлагает имя переименованной вкладки, а иначе — **Без названия**.
- **Портативный пакет** — файл проекта представляет собой ZIP-архив: JSON сессий и папка `media/` с байтовыми копиями оригиналов (без перекодирования пикселей).
- **Отсутствующие исходники при сохранении** — если путь из списка больше не существует, проект всё равно сохраняется: это изображение пропускается, а предупреждение перечисляет его.
- **Настройки приложения** — **Тема**, **Язык** и горячие клавиши остаются в настройках приложения и не входят в файл проекта.

### Двойной клик по файлу в Windows {#windows-file-association}

Установщик связывает `.imgsli` с Improve ImgSLI, поэтому двойной клик открывает проект, а файл получает значок документа приложения. Сборка для Windows также регистрирует связь при каждом запуске.

Если в свойствах файла по-прежнему указано «Выбор приложения», выберите Improve ImgSLI вручную один раз или запустите приложение с `--register-file-types`.
