## Горячие клавиши

Ниже — сочетания клавиш по умолчанию. Большинство действий переназначается в разделе **Настройки** → **Клавиатура**. Клавиши `WASD`, стрелки, `Space` на холсте и зум `+`/`-` зафиксированы и не переназначаются.

### Сначала поиск {#discover}

`Ctrl+Shift+P` плюс часть имени действия быстрее, чем прокрутка списка: **Найти действие** запускает выбранное действие или открывает **Подробнее** с иллюстрированной темой справки. Если элемент в фокусе привязан к действию, `F1` подсвечивает его в списке **Найти действие**.

### Платформа {#platform}

- `Ctrl+,` — **Настройки**
- `Ctrl+F1` — **Справка**
- `Ctrl+N` — **Открыть выбор сессии**
- `Ctrl+Tab` / `Ctrl+Shift+Tab` — следующая / предыдущая сессия
- `Ctrl+Shift+P` — **Найти действие**
- `Ctrl+V` — **Вставить изображение из буфера**
- `Ctrl+Shift+O` / `Shift+S` / `Ctrl+Shift+S` — **Открыть проект** / **Сохранить проект** / **Сохранить проект как…** (`.imgsli`)
- `Ctrl+Q` — **Выход**

Названия действий зависят от языка; свои сочетания задаются в разделе **Клавиатура** настроек, в группе платформенных действий.

`Shift+S` сохраняет проект в файл `.imgsli`, а `Ctrl+S` — результат текущего сравнения.

### Сравнение изображений {#image-compare}

- `M` / `F` — **Переключить лупу** / **Заморозить лупу**
- `N` / `D` — **Подписи имён файлов** / **Видимость разделителя**
- `H` / `C` — **Режим различий** / **Режим канала**
- `X` — **Поменять изображения**
- `R` / `Ctrl+E` — **Запись видео** / **Видеоредактор**
- `Ctrl+S` — **Быстрое сохранение**
- `WASD` / `QE` — движение лупы / расстояние между лупами (фиксировано)
- `Shift+Space` — превью стороны в комбинированном режиме (фиксировано)
- `←↑↓→` / `+` / `-` — панорамирование / зум (фиксировано)

Подробнее: [Сравнение](help://workspace.image_compare.comparison), [Лупа](help://workspace.image_compare.magnifier), [Видеоредактор](help://workspace.image_compare.video).

### Мультисравнение {#multi-compare}

- `Ctrl+O` — **Добавить изображения**
- `D` — **Видимость сетки**
- `Ctrl+S` — **Быстрое сохранение**
- `Esc` — выход из фокуса слота
- `←↑↓→` / `+` / `-` — панорамирование / зум (фиксировано)

См. [Обзор мультисравнения](help://workspace.multi_compare.overview).

### Окно видеоредактора {#video-editor}

Пока редактор открыт: `Space` — воспроизведение / пауза, `Ctrl+Z` / `Ctrl+Y` — отмена / повтор, `Delete` / `Backspace` — обрезка по выделению. Полный сценарий: [Видеоредактор](help://workspace.image_compare.video).

### Навигация с клавиатуры {#keyboard-navigation}

- `F1` — контекстная справка для элемента в фокусе. Если фокус привязан к действию, совпадение подсвечивается в **Найти действие**; иначе **Найти действие** открывается с фильтром по теме.
- В **Найти действие** (`Ctrl+Shift+P`): `↑` / `↓` — перемещение по списку, `Enter` — запуск, `Ctrl+Enter` — **Подробнее**, `Esc` — закрыть.
- В **Мультисравнении** фокус следует за указателем: клик включает и выключает фокус на одном изображении, `Esc` выходит из него. Стрелки панорамируют холст, а не перемещают фокус между слотами.
- На странице **Выбор сессии** стрелки перемещают фокус между карточками, а `Enter` открывает карточку в фокусе — как клик по ней.
- Обхода слотов холста клавишей `Tab` нет: фокус следует за указателем, а клавиатура управляет действиями через **Найти действие**.
