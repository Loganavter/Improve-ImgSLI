## 快捷键

下面列出默认快捷键。大多数操作可以在 **设置 → 键盘** 中重新绑定；画布上的 `WASD`、方向键、`Space`（移动）和 `+`/`-`（缩放）是固定按键，无法重新绑定。

### 先搜索，再记忆 {#discover}

与其背下一长串快捷键，不如按 `Ctrl+Shift+P` 输入名称：**查找操作** 会直接运行找到的操作；该操作有图文说明时，可以打开 **了解更多**。当焦点所在的控件带有关联操作时，按 `F1` 会高亮对应的操作。

### 平台 {#platform}

- `Ctrl+,` — **设置**
- `Ctrl+F1` — **帮助**
- `Ctrl+N` — **会话选择器** / **新建会话**
- `Ctrl+Tab` / `Ctrl+Shift+Tab` — 切换到下一个 / 上一个工作区会话
- `Ctrl+Shift+P` — **查找操作**
- `Ctrl+V` — 粘贴图像
- `Ctrl+Shift+O` / `Shift+S` / `Ctrl+Shift+S` — **打开** / **保存** / **另存为** 项目（`.imgsli`）
- `Ctrl+Q` — **退出**

显示的名称取决于所用语言包；重新绑定在 **设置 → 键盘 → 平台** 分组中进行。

### 图像比较 {#image-compare}

- `M` / `F` — **放大镜** / **冻结**
- `N` / `D` — **文件名标签** / **分割线可见性**
- `H` / `C` — **差异模式** / **通道模式**
- `X` — **交换**
- `R` / `Ctrl+E` — **录制** / **视频编辑器**
- `Ctrl+S` — **快速保存**
- `WASD` / `QE` — 移动放大镜 / 调整间距（固定不变）
- `Shift+Space` — 组合模式下预览单侧图像（固定不变）
- `←↑↓→` / `+` / `-` — 平移 / 缩放（固定不变）

详情见 [对比](help://workspace.image_compare.comparison)、[放大镜](help://workspace.image_compare.magnifier)、[视频编辑器](help://workspace.image_compare.video)。

### 多图比较 {#multi-compare}

- `Ctrl+O` — **添加图像**
- `D` — **网格可见性**
- `Ctrl+S` — **快速保存**
- `Esc` — 退出槽位焦点
- `←↑↓→` / `+` / `-` — 平移 / 缩放（固定不变）

见 [多图比较](help://workspace.multi_compare.overview)。

### 视频编辑器窗口 {#video-editor}

编辑器打开时：`Space` 播放或暂停，`Ctrl+Z` / `Ctrl+Y` 撤销或重做，`Delete` / `Backspace` 按当前选区裁剪。完整的编码流程见 [视频编辑器](help://workspace.image_compare.video)。

### 键盘导航 {#keyboard-navigation}

- `F1` — 显示焦点控件的上下文帮助。当焦点与某个操作关联时，**查找操作** 中的匹配项会高亮；否则按主题预过滤后打开 **查找操作**。
- 在 **查找操作**（`Ctrl+Shift+P`）中：`↑` / `↓` 移动选择，`Enter` 运行，`Ctrl+Enter` 打开 **了解更多**，`Esc` 关闭。
- 在 **多图比较** 概览中，槽位焦点跟随指针：单击切换单图聚焦，`Esc` 退出。方向键用于平移画布，不会在槽位之间移动焦点。
- 在 **会话选择器** 中，方向键在卡片之间移动焦点，`Enter` 打开聚焦的卡片，效果等同于单击该卡片。
- 画布槽位之间不能用 `Tab` 遍历：焦点跟随指针，键盘通过 **查找操作** 驱动操作。
