## 文件与项目

将图像加载到会话列表中，从剪贴板粘贴图像，并打开或保存便携式项目文件——其中包含会话布局、对比设置以及源图像的副本。

### 加载图像 {#loading-images}

- **添加文件** — 点击任一侧列表上方的添加按钮来选择一个或多个文件；也可以按 `Ctrl+Shift+P` 打开 **查找操作** 并运行同名操作。
- **拖放** — 将文件拖入窗口，文件会进入光标所在一侧的列表。
- **粘贴**（`Ctrl+V`）— 把剪贴板中的图像放入列表：窗口会出现方向浮层，单击箭头选择左侧或右侧，按 `Esc` 取消。

:::figure{side=block width=280}
![粘贴方向浮层](../../assets/platform/paste_overlay.jpg)
按 `Ctrl+V` 后出现的方向浮层：用箭头选择图像进入哪一侧列表。

### 列表 {#lists}

- **图像比较** — 左右两个列表互相独立；列表管理面板可以重新排序、评分、重命名、查看路径、**属性** 和删除，详见 [对比](help://workspace.image_compare.comparison)。
- **多图比较** — 图像按槽位逐个拖入，不使用左右两个列表，详见 [多图比较](help://workspace.multi_compare.overview)。

### 项目 {#projects}

- **打开 / 保存** — 通过文件菜单或 **查找操作** 打开和保存 `.imgsli` 项目；快捷键为 `Ctrl+Shift+O`（打开）、`Shift+S`（保存）和 `Ctrl+Shift+S`（另存为）。
  - **保存项目** 把改动写入当前文件；文件尚未保存过时，会先打开项目另存为…。
  - **项目另存为…** 在标签页已命名时使用该名称，否则使用 **未命名**；打开项目后，当前标签页改用项目文件名。
  - 项目会恢复工作区会话、对比设置（**分割线**、**差异模式**、**放大镜** 及相关功能）以及嵌入的图像副本。
- **便携包** — 项目文件是一个 ZIP 包：内含会话数据的 JSON 和 `media/` 文件夹中的原始图像字节副本。图像不会被重新压缩，因此项目可以脱离原文件移动和打开。
- **保存时缺少源文件** — 当列表中某个文件的路径已不存在时，项目仍会保存：该图像被跳过，并在警告中列出。
- **应用偏好** — **主题**、**语言** 和键盘快捷键保存在应用设置中，不属于项目文件，所以打开其他项目时它们保持不变。
