## 文件与项目

把图像加载进会话列表，从剪贴板粘贴图像，并打开或保存一个项目文件——它打包了会话布局、对比设置和源图像的副本。

### 加载图像 {#loading-images}

- **添加图像1** / **添加图像2** — 左右两个列表旁的添加按钮会打开文件选择器；为对应一侧挑选一张或多张图像。
- **添加图像** — 在 **多图比较** 中，单个添加按钮把图像加载进网格。
- **拖放** — 把文件拖入窗口，它们会落在光标所在一侧的列表中。
- **从剪贴板粘贴图像**（`Ctrl+V`）— 图像进入当前会话。随后出现方向浮层：单击箭头选择一侧，或按 `Esc` 取消。

:::figure{side=block width=280}
![粘贴方向浮层](../../assets/platform/paste_overlay.jpg)
按 `Ctrl+V` 后的方向浮层：单击箭头，把粘贴的图像送入左侧或右侧列表。
:::

### 列表 {#lists}

- 在 **图像比较** 中，左右两个列表彼此独立。列表管理面板可以重新排序、评分、重命名、查看路径、打开属性以及删除图像——见 [对比](help://workspace.image_compare.comparison)。
- 在 **多图比较** 中，图像被放入各自的槽位，而不是两个列表——见 [多图比较](help://workspace.multi_compare.overview)。

每个会话都有自己的标签页；见 [标签页](help://platform.tabs)。

### 项目 {#projects}

项目文件（`.imgsli`）把整块工作区存进一个可移植文件：打开的会话、它们的对比设置，以及源图像的副本。

- **打开项目** — 在 **文件** 菜单、`Ctrl+Shift+O` 或 **查找操作** 中。当前标签页会采用文件名，项目会恢复会话、对比设置（分割线、差异、放大镜及相关功能）以及嵌入的图像副本。
- **保存项目** — `Shift+S` 写入当前文件。若尚无文件，则改为打开 **项目另存为…**。当标签页被重命名后，保存也会更新文件名。
- **项目另存为…** — `Ctrl+Shift+S` 建议使用重命名后的标签页名称，否则使用 **未命名**。
- **文件内容** — 一个 ZIP 归档：`project.json` 存放会话，`media/` 文件夹保存每张图像的嵌入副本。
- **源文件缺失时** — 当列出的某个路径不再存在时，项目仍会保存；该图像被跳过，警告中会指出它的名字。
- **不保存的内容** — 主题、语言和快捷键留在应用设置中；它们不属于项目文件。

### 在 Windows 上双击项目 {#windows-file-association}

在 Windows 上，安装程序会把 `.imgsli` 与 BlinkTable 关联，因此双击项目即可打开它，文件也会显示应用的文档图标。打包版本还会在启动时注册该关联。

如果「属性」中仍显示「选择应用程序」，请手动选择一次 BlinkTable，或用 `--register-file-types` 运行应用以重新注册关联。
