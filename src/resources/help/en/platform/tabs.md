## Tabs

The tab strip above the workspace holds one tab per open session. The active tab decides what the canvas, toolbar, and lists show, so switching tabs changes the whole workspace view.

### Tab strip {#tab-strip}

- **Switch** — click a tab to activate that session.
- **Reorder** — drag a tab along the strip to move it. The order is kept for the rest of the session and is saved with the project, and the tab you were on stays active at its new place. Ctrl+Tab and Ctrl+Shift+Tab always follow the order you see.
- **Close** — the close control removes the tab's session. Closing the last session replaces it with the **Session Picker**, so the strip never stands empty.
- **Context menu** — right-click a tab to rename it, duplicate it, close the other tabs, or open a new tab of any connected type. **Duplicate** stays hidden on the **Session Picker** itself, and closing the others appears only when more than one session is open.
- **Tab names** — a tab that was never renamed shows the session-type name in the current language. Renaming stores a custom title that survives language switches, so a renamed tab keeps its name when you change the interface language.
- **Shrinking and scrolling** — when the window narrows, tabs compress first, leaving a couple of letters of the name; the arrows at the strip's edges appear only when even those tabs no longer fit. The arrows scroll by one tab per click (hold to keep scrolling), and the mouse wheel scrolls the strip too — it never switches the active tab.
