## About

{{tr:app.name}} is a desktop workspace for precise image and media comparison. Side-by-side and multi-image views, pixel-scale difference inspection, still export, and comparison video recording.

### What it is for {#purpose}

Comparison of visual change with the context kept: retouching, upscaling QA, photography — sessions where a split, a magnifier, and an exportable result matter more than a one-off screenshot.

### Workspace modes {#modes}

One card per connected tab; the set grows with the installed tabs. {{tr:workspace.session_types.image_compare}} compares image pairs with a movable split, magnifiers, and difference modes — [Comparison](help://workspace.image_compare.comparison). {{tr:workspace.session_types.multi_compare}} lays many images into a grid of slots — [{{tr:workspace.session_types.multi_compare}}](help://workspace.multi_compare.overview). The session picker card opens, resumes, and manages sessions — [Workspace Tabs](help://workspace.session_picker). First orientation: [Getting Started](help://platform.getting_started).
