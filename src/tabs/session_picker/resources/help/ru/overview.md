## Обзор выбора сессии

Домашняя страница {{tr:session_picker.tab_name}} создаёт сессии рабочей области и открывает недавние проекты `.imgsli`. Основы полосы вкладок — на странице [Вкладки рабочей области](help://session_picker).

### Открытие и создание сессии {#open-create}

- **Карточки** — выберите {{tr:workspace.session_types.image_compare}} или {{tr:workspace.session_types.multi_compare}}, чтобы создать сессию этого типа.
- **Без выбора** — выполните {{tr:action.workspace.new_image_compare}} или {{tr:action.workspace.new_multi_compare}} через {{tr:menu.find_action}} (`Ctrl+Shift+P`).
- **Домой** — {{tr:action.workspace.open_session_picker}} возвращает на эту страницу, когда удобнее выбирать визуально.

### Недавние проекты {#recent-cards}

- **Открытие** — нажмите на карточку, чтобы открыть проект; карточки с удалённым файлом остаются в списке, но не открываются.
- **Правая кнопка** — Открыть, Свойства (метаданные файла, см. [Свойства изображения](help://image_properties)), Убрать из списка и Показать в папке.
- **Шапка** — переключение Сетка / Список и сортировка по дате модификации, дате создания или по имени, по возрастанию или по убыванию.
- **Закрепление** — перетащите файл `.imgsli` на панель, чтобы закрепить его в списке не открывая.

### Клавиатура {#keyboard}

Стрелки перемещают между карточками, `Enter` открывает выбранный проект — полный список см. в разделе [Горячие клавиши](help://hotkeys#keyboard-navigation).
