## Session Picker Overview

The {{tr:session_picker.tab_name}} home page creates workspace sessions and reopens recent `.imgsli` projects. Tab-strip basics live on [Workspace Tabs](help://session_picker).

### Open or create a session {#open-create}

- **Cards** — pick {{tr:workspace.session_types.image_compare}} or {{tr:workspace.session_types.multi_compare}} to create that session type.
- **Without the picker** — run {{tr:action.workspace.new_image_compare}} or {{tr:action.workspace.new_multi_compare}} from {{tr:menu.find_action}} (`Ctrl+Shift+P`).
- **Back home** — {{tr:action.workspace.open_session_picker}} returns to this page when you want to choose visually.

### Recent projects {#recent-cards}

- **Open** — click a card to reopen the project; cards whose file is gone stay listed but cannot be opened.
- **Right-click** — Open, Properties (file metadata, see [Image Properties](help://image_properties)), Remove from list, and Show in folder.
- **Header** — switch Grid / List view and sort by date modified, date created, or name, ascending or descending.
- **Pin** — drop an `.imgsli` file onto the panel to pin it to the list without opening.

### Keyboard {#keyboard}

Move between cards with the arrow keys and open the focused project with `Enter` — the full list lives under [Hotkeys](help://hotkeys#keyboard-navigation).
