## Session Picker and Tabs

New-tab home page and project history.

### Session Picker {#session-picker}

- **Session types** — {{tr:workspace.session_types.image_compare}}, {{tr:workspace.session_types.multi_compare}}, {{tr:image_gallery.tab_name}}.
- **Recent** — ``.imgsli`` projects. Click opens; right-click: open, properties, remove, reveal in folder.
- **Pin** — drop a project file onto the panel to add it to the list.
- **View** — grid or list, sort by date or name.

### Keyboard {#keyboard}

Move between cards with the arrow keys and open the focused project with `Enter` — the full list lives under [Hotkeys](help://hotkeys#keyboard-navigation).

### Tab strip {#tab-strip}

- **Switch** — click a tab.
- **Close** — removes that session; if it was the last one, the Session Picker opens instead of quitting.
- **Context menu** — rename, close, or close other tabs.

### Rename a tab {#rename}

Use the tab context menu rename action, enter a name, and confirm. Auto titles stay language-aware until you set a custom name.
