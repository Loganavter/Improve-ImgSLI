## 视频编辑器

把实时 **图像比较** 会话录制成控制轨道，可在时间轴上裁剪并编码为视频或 GIF。静态图像请见[导出](help://workspace.export)。

### 录制会话 {#recording}

- **开始 / 暂停 / 停止** — 用 **录制视频**（`R`）开始，用 **暂停录制** 暂停，停止也由同一组控件完成。
- **记录内容** — 记录的是画布操作（缩放/平移、分割线、放大镜、已加载图像及相关设置）随时间变化的控制轨道与采样点，而不是原始屏幕录像；因此回放能与实时会话保持一致。
- **采集帧率** — 在[设置](help://platform.settings#image_compare)的 **图像比较** 分区中设置 **录制帧率**。

### 打开编辑器 {#open-editor}

停止录制后，**视频编辑器**（`Ctrl+E`）可以逐帧拖动查看、编辑范围并导出。在 **查找操作** 中搜索编辑器相关控件，也会打开本主题。

### 时间轴编辑 {#timeline}

- **拖动定位** — 拖动时间指示器浏览各帧。
- **选取范围** — 按住 `Shift` 拖动可标记一段范围；两端手柄与选区中部可分别移动；**裁剪到选择** 只保留该选区。
- **删除** — 用 `Delete` / `Backspace` 删除选中的范围。
- **播放** — 用 `Space` 播放或暂停；撤销 / 重做用 `Ctrl+Z` / `Ctrl+Y`。

### 轨道与记录内容 {#tracks}

工具轨道（分割线、放大镜、视口等）显示被记录的控件随时间如何变化；在采样点之间，编辑器会插值数值，让回放与实时会话保持一致。放大镜把 **Capture Position**（图像上捕获环的位置）和 **Offset**（镜头相对捕获点的偏移）记录为两条独立轨道。要修改结果，在时间轴上裁剪或删除相应范围，再配合撤销 / 重做。

### 预览质量 {#preview-quality}

**预览质量** 只降低编辑器内预览的画质以提升响应速度，不影响最终编码质量。

- **完整 (1.0x)** — 预览最清晰，对设备负载最大，为默认选项。
- **平衡 (0.75x)** — 兼顾清晰度与流畅度，适合大多数会话。
- **性能 (0.5x)** — 拖动时感觉卡顿时可选用的更轻量预览。
- **草稿 (0.25x)** — 预览速度最快，细节最少。

### 导出视频或 GIF {#export-encode}

- **画面** — 设置分辨率（可按需锁定宽高比）、帧率（不能高于录制帧率），并选择适配或裁剪；边缘留白时可指定填充颜色。
- **编码器** — 在标准标签页中选择容器格式与编码器；硬件编码器只在系统支持时显示。
- **质量** — 用 CRF/CQ 或比特率控制画质，并选择相应预设。
- **路径** — 指定输出文件；收藏目录按钮可复用上次使用的文件夹。
- **进度** — 编码可随时停止；日志会显示编码器的输出信息。

### 手动命令行 {#manual-cli}

当标准标签页无法满足需求时，可以用 **手动命令行** 标签页直接传入原始 FFmpeg 输出参数。参数需要自行拼写，请只在你清楚各选项含义时使用；无效参数会导致编码失败。
