## 询问 AI

你可以就单张卡片、当前选中项或整个系列提问。回答仅供参考，并且始终带有一个标记，表明它由 AI 提供。

### 就选中项提问 {#ask-selection}

- **AI…** — 为该卡片或当前选中项打开 **询问 AI**。
- **默认提示词** — 问题 **这里有什么重点？** 让模型概括它收到的图像。
- **标记** — **AI 解读，未经核实** 标记标出由 AI 生成、未经你核实的文本。

### 就系列提问 {#ask-series}

系列的标题菜单会一次对系列中的每个成员提问。锐度或噪点的分数来自 [质量指标](help://workspace.image_gallery.quality)，显示时无需向 AI 模型发起请求。

### 设置与限制 {#setup}

- **AI 设置** — 在 **设置** 中配置 **图库 — AI**；提问需要 **启用 AI 图像分析**、一个 API 密钥和一个模型。缺少它们时，应用会显示 **请先在设置中配置 AI API 密钥。**
- **进度与错误** — 模型处理期间，面板会显示 **思考中…**；请求失败会报告 **AI 无法回答。**
- **仅供参考** — 回答绝不会改变排名、选中项或任何已存储状态。
- **缓存** — 相同的问题会复用缓存的回答；更换模型或图像变化会重新请求模型。
