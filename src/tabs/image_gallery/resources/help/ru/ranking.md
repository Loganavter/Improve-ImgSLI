## Ранжирование: Алгоритмы и ИИ

Каждая серия получает ранг — какое изображение лучше. Переключатель на панели инструментов между **Алгоритмы** и **ИИ** решает, кто ранжирует.

### Алгоритмы {#algorithms}

Ранжировщик по умолчанию. Он объединяет измеренные показатели в один детерминированный порядок: одни и те же изображения с теми же показателями дают один и тот же ранг всегда, а при равенстве порядок решает путь к файлу, а не порядок загрузки папки. Какие показатели учитываются, зависит от папки — см. [Метрики качества](help://workspace.image_gallery.quality#modes).

- Изображение без измерений не показывает номер ранга.
- Ранг упорядочивает изображения только внутри одной серии.

### ИИ {#ai}

Необязательный. Когда включён переключатель **ИИ**, ИИ ранжирует серию по собственной оценке качества каждого изображения, а не по измерениям приложения. Этот ранг не фиксирован: одна и та же серия может вернуться в другом порядке, а в полосе статистики видно **Ранжировано: ИИ (Jev)**, так что его не спутать с чтением **Алгоритмы**.

- Ранг сохраняется по серии, поэтому повторный запуск стабилен, пока серия не изменится.
- Когда ИИ недоступен или не уверен, ранг возвращается к **Алгоритмы** с показанной причиной, так что ранг не меняется без видимой причины.

### Чтение ранга {#badge}

- Карточка показывает номер ранга; победитель серии вместо номера показывает **★ BEST**.
- В полосе статистики видно, кто получил номера: **Ранжировано: Алгоритмы**, **Ранжировано: ИИ (Jev)** или **Ранжировано: Вручную**, если победителя выбрали через **Оставить лучшее** / **Сделать лучшим**.
- Изображение без ранга не показывает номер.
