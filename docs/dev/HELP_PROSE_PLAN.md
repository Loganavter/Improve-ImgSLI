# Plan: привести страницы справки к гайдлайну

Цель: все тела справки написаны по [HELP_AUTHORING.md](./HELP_AUTHORING.md) —
пользовательский док с механикой и дальнозоркостью, без обучалки, мета-нарратива,
цементирования открытых множеств и смешения уровней.

Не-цели: менять механику справки (дерево, токены, фигуры, merge); трогать
рендерер; новые фичи.

## Фазы

### Ф0 — Базлайн и заморозка

Зафиксировать текущее дерево и инварианты: help-сuites зелёные, фигуры 0
missing, наборы якорей/ключей/ссылок сняты скриптом в `docs/dev/help-prose-baseline.txt`
(для diff `пусто` на каждой волне). Здесь же — тест-пробы на ложные факты
(§3.2 гайдлайна): одиночный дроп, set-as-source, fidelity-manual, AI-гейт.

### Ф1 — `sessions.md` (образцовая переработка)

Первый и показательный: развести уровни. Полоска вкладок и клавиатура — это
хост-хром, не поверхность выбора сессии. Решение по размещению (в план):
- либо полоска вкладок уезжает в host-страницу (`platform.*`), а пикер
  становится чистой страницей выбора сессии;
- либо секция остаётся, но явным кросс-уровневым блоком со ссылкой.
Убрать `Пин`/`Вид` — заменить механикой (карточки соединённых вкладок;
недавние; сорт/вид как свойства панели). Открытое множество — «например».
Убрать противоречие с переименованием (один источник правды). RU+EN.
Якоря сохранить (`session_picker`, `keyboard`, `new-session-actions`,
`tab-strip`, `rename`, `next-topics`).

### Ф2 — gallery, 4 страницы

`overview` / `triage` / `quality` / `ask_ai` — по гайдлайну: номинантный
голос, пункт = понятие, без «вы» и целей. Закрепить 4 исправленных факта
пробами. EN; RU — фолбэк (RU пока нет — не копировать).

### Ф3 — multi_compare, 4 страницы

`overview` / `layouts` / `viewing` / `export`. Вынести аккорд-таблицу из
`viewing.md` в inline-определения + ссылку на hotkeys. `Cap` с опорой на
константу. Открытые множества (раскладки, режимы) — механизм.

### Ф4 — Аудит host + IC страниц

`ui/buttons.md` (канон, но с браком: убрать `Где/Что/Насколько плотный`,
мета-нарратив), `ui/lists_flyouts.md`, `ui/canvas_navigation.md`,
`platform/*`, IC `comparison/magnifier/video`, SP `sessions`. Проверить
каждую по §1–§3; править только найденное. Канон не ломать без причины.

### Ф5 — Доки

`HELP_SYSTEM.md`: сослаться на `HELP_AUTHORING.md`, убрать устаревшую
строку «no GFM pipe tables» (таблицы рендерятся — `TableBlock`).
